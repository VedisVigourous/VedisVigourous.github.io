### 2️⃣ 🎮 **Number Guessing Game**

**Status:** ✅ Completed | **Location:** `/NumberGuesser`

An interactive JavaScript game where players test their intuition and logic to guess the mystery number!

#### ✨ Features
- **Smart Game Logic** - Random number generation with attempt tracking
- **Real-time Feedback** - Instant hints (higher/lower) to guide your guesses
- **Score System** - Tracks number of attempts and challenges players to beat their records
- **Interactive UI** - Clean, user-friendly interface with responsive design
- **Replay Functionality** - Play multiple rounds without page refresh
- **Dynamic Messages** - Motivational and contextual feedback based on gameplay

#### 🛠️ Technology Stack
- **HTML5** - Semantic markup for game structure
- **CSS3** - Stylish, responsive UI with smooth transitions
- **Vanilla JavaScript** - Pure game logic with no dependencies
  - DOM manipulation for real-time updates
  - Event handling for user interactions
  - Algorithm optimization for game mechanics

#### 🎮 How to Play
1. The game thinks of a number between 1 and 100
2. Enter your guess in the input field
3. Get hints: "Too High!" or "Too Low!"
4. Keep guessing until you find the number
5. Challenge yourself to guess in fewer attempts!
